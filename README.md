# Рубежный контроль 1

Курс «Парадигмы и конструкции языков программирования».
Вариант запросов Г, предметная область 30: факультет и университет.

## Запуск

Нужен только Python 3. Дополнительные библиотеки не используются.

```bash
python3 rk1.py
```

Программа выполняет три запроса:

1. Выводит университеты на букву «А» и их факультеты.
2. Для каждого университета находит максимальное число студентов на одном
   факультете и сортирует результаты по возрастанию этого числа.
3. Выводит пары факультетов и университетов для связи многие ко многим,
   отсортированные по названию университета.

Все данные учебные и записаны прямо в программе. В первых двух запросах
факультет относится к одному университету. В третьем запросе используется
отдельный список связей: факультет информатики связан с двумя университетами.
